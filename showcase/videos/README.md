# Record the demo videos

> **Language:** English | [Русская версия](README_RU.md)

Two recordings are embedded in the [root README](../../README.md#showcase-videos): a custom server menu and a walkthrough of the bundled demo menus.

For new recordings, use these scenarios:

| Menu           | Recording                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------- |
| `demo_main`    | Open the menu, hover controls, enter a name, toggle notifications, and trigger the cooldown |
| `demo_gallery` | Select all three templates, show the book tooltip and personal avatar                       |
| `demo_states`  | Activate and reset the scene, then show denied and allowed permission states                |

To add or replace a clip, attach an MP4 through the GitHub Markdown editor. Copy the generated attachment URL into both root README files on a separate line so GitHub displays a video player. Keep the heading and description above it. H.264 video with AAC audio is suitable for browser playback.

Follow the [demo walkthrough](../README.md) to prepare permissions and menu files. Record in 16:9 against a quiet background. Move the cursor slowly enough for hover feedback to be visible, and include navigation and actionbar messages in the frame. Check the client framing before recording.

The YAML examples are bundled plugin resources. Recording instructions, thumbnails, and videos belong outside the plugin JAR.
