# Record the demo videos

> **Language:** English | [Русская версия](README_RU.md)

The root README has three video placeholders. Upload recordings to a public video host and replace the matching marker with its link.

| Marker                   | Menu           | Recording                                                                                   |
| ------------------------ | -------------- | ------------------------------------------------------------------------------------------- |
| `VIDEO_INTERACTIONS_URL` | `demo_main`    | Open the menu, hover controls, enter a name, toggle notifications, and trigger the cooldown |
| `VIDEO_GALLERY_URL`      | `demo_gallery` | Select all three templates, show the book tooltip and personal avatar                       |
| `VIDEO_STATES_URL`       | `demo_states`  | Activate and reset the scene, then show denied and allowed permission states                |

Follow the [demo walkthrough](../README.md) to prepare permissions and menu files. Record in 16:9 against a quiet background. Move the cursor slowly enough for hover feedback to be visible, and include navigation and actionbar messages in the frame. Check the client framing before recording.

The YAML examples are bundled plugin resources. Recording instructions, thumbnails, and videos belong outside the plugin JAR.
