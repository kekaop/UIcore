# Video slots

The root README has one slot for each kind of video. Replace the placeholder URL with the final YouTube, GitHub Release, or other public video link after uploading it.

Suggested filenames and topics:

- `full-tour` — short tour of UIcore and the main menu.
- `interactions` — hover, click, states, and input fields.
- `dragging` — group dragging and single-element rotation.
- `integrations` — Vault and LuckPerms in a live menu.
- `slots-and-schematics` — slot templates and per-player schematic previews.

Do not place private server addresses, player names, credentials, or configuration secrets in a recording.
