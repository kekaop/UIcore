# Записать демонстрационные видео

> **Язык:** [English](README.md) | Русский

В основном README есть три места для видео. Загрузи записи на публичный видеохостинг и замени соответствующий маркер ссылкой.

| Маркер                   | Меню           | Сценарий                                                                            |
| ------------------------ | -------------- | ----------------------------------------------------------------------------------- |
| `VIDEO_INTERACTIONS_URL` | `demo_main`    | Открытие, наведение, ввод имени, переключатель уведомлений и задержка между кликами |
| `VIDEO_GALLERY_URL`      | `demo_gallery` | Выбор трёх шаблонов, подсказка книги и персональный аватар                          |
| `VIDEO_STATES_URL`       | `demo_states`  | Активация и сброс сцены, затем запрещённый и разрешённый доступ по правам           |

Подготовь файлы и права по [инструкции демонстрации](../README_RU.md). Записывай в 16:9 на спокойном фоне. Двигай курсор достаточно медленно, чтобы было видно наведение. Оставь в кадре навигацию и сообщения actionbar. До записи проверь, как меню выглядит в клиенте.

YAML-примеры входят в ресурсы плагина. Инструкции записи, обложки и видео находятся вне JAR.
