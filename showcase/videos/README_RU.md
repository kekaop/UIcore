# Места для видео

В корневом README подготовлены места для пяти роликов. После загрузки замените соответствующий маркер ссылкой на YouTube, GitHub Releases или другой публичный хостинг.

Предлагаемые имена и темы:

- `full-tour` — короткий обзор UIcore и главного меню.
- `interactions` — наведение, клик, состояния и поля ввода.
- `dragging` — перемещение группы и вращение отдельного элемента.
- `integrations` — Vault и LuckPerms в работающем меню.
- `slots-and-schematics` — шаблоны слотов и персональные превью схем.

Не показывайте в записи адреса приватного сервера, имена игроков, пароли, токены и секреты конфигурации.
