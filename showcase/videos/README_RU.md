# Записать демонстрационные видео

> **Язык:** [English](README.md) | Русский

В [русском README](../../README_RU.md#видео) доступны две записи: пример меню сервера и обзор демонстрационных меню плагина.

Для новых записей используй эти сценарии:

| Меню           | Сценарий                                                                            |
| -------------- | ----------------------------------------------------------------------------------- |
| `demo_main`    | Открытие, наведение, ввод имени, переключатель уведомлений и задержка между кликами |
| `demo_gallery` | Выбор трёх шаблонов, подсказка книги и персональный аватар                          |
| `demo_states`  | Активация и сброс сцены, затем запрещённый и разрешённый доступ по правам           |

Чтобы добавить или заменить ролик, прикрепи MP4 в редакторе Markdown на GitHub. Вставь полученную ссылку на вложение отдельной строкой в оба основных README — тогда GitHub покажет видеоплеер. Над ссылкой оставь заголовок и описание. Для воспроизведения в браузере подходит видео H.264 со звуком AAC.

Подготовь файлы и права по [инструкции демонстрации](../README_RU.md). Записывай в 16:9 на спокойном фоне. Двигай курсор достаточно медленно, чтобы было видно наведение. Оставь в кадре навигацию и сообщения actionbar. До записи проверь, как меню выглядит в клиенте.

YAML-примеры входят в ресурсы плагина. Инструкции записи, обложки и видео находятся вне JAR.
