# UIcore Lab

[English](README.md)

Пять связанных экранов для показа UIcore 1.1. Витрина использует ванильные предметы, текст и декорацию из Sponge-схемы. Игроку не нужен мод или ресурс-пак.

1. На тестовом сервере с UIcore 1.1 и PacketEvents скопируй содержимое папок `menu/`, `cutscenes/` и `schematics/` в одноимённые папки внутри `plugins/UIcore/`.
2. Оставь `use-player-location: false` в `config.yml`. Пример использует мир `world` и фиксированную камеру около `0.5, 110, 0.5`. При переносе поменяй вместе координаты пяти камер, мировой якорь схемы и точки тура.
3. Запусти сервер или перезагрузи UIcore, когда витрина закрыта. Проверь маршрут через `/uicore cutscene validate` и открой `/uicore run showcase_lab`. Если команда выполняется из консоли, добавь ник игрока в конец.
4. Для записи включи дневное освещение на тестовом сервере и полноэкранный режим в клиенте. Схема не меняет уровень света в мире.

| Экран | Что показать |
| --- | --- |
| Gallery | Compass, Geode и Relay меняют содержимое центрального слота для зрителя. Наведи курсор на экспонат и сравни его с отображением аватара. |
| Controls | Прокрути колесо, сдвинь панель за заголовок, затем перенеси алмаз в гнездо. Ползунок меняет сигнал с шагом. Первый клик захватывает элемент, второй сбрасывает. |
| Terminal | Activate и Reset меняют материал, подпись и видимость. Для ввода нажми **Set callsign**, затем T и введи тестовый позывной. |
| Camera Tour | Запусти тур, выбери **Observation** или **Systems**, затем дождись возврата камеры. |

Декорация видна только участнику меню. При закрытии UIcore возвращает ему вид настоящих блоков. Сцену не нужно строить в мире, а необязательные плагины для неё не требуются. Экспериментальное удержание ЛКМ можно показать отдельно на встроенном `demo_drag`.
