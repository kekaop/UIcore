# Пакет материалов для showcase UIcore

[English version](README.md).

В этой папке находятся материалы для README и демонстрационных роликов UIcore. Она специально расположена за пределами `uicore-plugin/src/main/resources`, поэтому Maven не копирует её в JAR плагина.

## Порядок записи роликов

1. `showcase_main.yml` — открытие меню и переход к демонстрациям.
2. `showcase_interactions.yml` — наведение, клик, состояния элементов и ввод через чат.
3. `showcase_drag.yml` — перемещение группы и отдельное вращение элемента.
4. `showcase_integrations.yml` — баланс Vault, группа, префикс и суффикс LuckPerms.
5. `showcase_slots.yml` — шаблоны слотов и переходы предметов.

Для локальной проверки скопируйте нужный файл в `plugins/UIcore/menu/`, выполните `/uicore reload`, затем откройте его командой `/uicore run <id-меню>`. Эти файлы предназначены только для showcase и не устанавливаются сборкой.

Папка `videos/` зарезервирована под ссылки, превью и заметки для записи. После публикации роликов замените маркеры в корневом README.
