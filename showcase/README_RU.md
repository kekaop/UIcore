# Демонстрация UIcore

> **Язык:** [English](README.md) | Русский

Три демонстрационных меню одновременно служат базовыми примерами плагина. YAML-файлы находятся в [ресурсах меню](../uicore-plugin/src/main/resources/menu); в этой папке лежат инструкции по проверке и записи видео.

| Меню                                                                      | Что показать                                                              |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| [demo_main](../uicore-plugin/src/main/resources/menu/demo_main.yml)       | Наведение, смена курсора, ввод через чат, переключатель и задержка кликов |
| [demo_gallery](../uicore-plugin/src/main/resources/menu/demo_gallery.yml) | Статичные предметы, аватар игрока и три шаблона в персональном слоте      |
| [demo_states](../uicore-plugin/src/main/resources/menu/demo_states.yml)   | Изменение текста, материала и видимости, оформление и доступ по правам    |

## Установить и открыть меню

При первой установке плагин создаст эти три меню автоматически. На существующем сервере:

1. Сохрани копию своего `demo_main.yml`, если менял его.
2. Скопируй все три YAML-файла из исходников в `plugins/UIcore/menu/`.
3. Удали старые демонстрационные файлы с сервера, если они больше не нужны. Обновление плагина не удаляет существующие меню.
4. Выполни `/uicore reload`, затем `/uicore run demo_main`.

Для проверки нужны права `uicore.start`, `uicore.close` и `uicore.slot`. Для перезагрузки администратору нужно `uicore.reload`. С OP команды доступны по умолчанию. Для демонстрации ограничений используй игрока без OP и выдай ему необходимые права на команды отдельно.

Ресурс-пак и дополнительные интеграции не требуются. Камера размещается относительно позиции игрока при открытии; кнопка **Close** возвращает его на исходное место. В исходном конфиге стоит `cursor-item.z-offset: 1.0`. Существующий конфиг сервера сохраняет прежнее значение; при необходимости измени его вручную.

## Показать взаимодействия

В **demo_main**:

1. Наведи курсор на поле имени и **Send signal**, чтобы показать смену цвета и курсора.
2. Нажми **Save name** при пустом поле — появится сообщение об отказе в actionbar.
3. Нажми поле имени, введи короткое имя в чат и снова нажми **Save name**.
4. Дважды нажми **Notifications**, чтобы показать оба текста и стиля.
5. Дважды нажми **Send signal** в течение трёх секунд — второй клик покажет оставшееся время ожидания.

Поле имени и уведомления показывают работу интерфейса. Они не изменяют внешний профиль или сервис уведомлений.

## Переключить предметы в галерее

Открой **Gallery** и последовательно нажми **Knight**, **Miner**, **Scout**. В центральном слоте сменится шаблон. Наведи курсор на книгу и аватар для показа подсказок. При проверке вдвоём выберите разные шаблоны: выбор одного игрока не должен менять предмет другого.

Выбранный шаблон может сохраняться после повторного открытия. Вернуть исходный можно командой `/uicore slot reset <player> demo_gallery loadout`.

## Показать состояния и права

Открой **States**. Кнопка **Activate** меняет текст статуса, заменяет уголь изумрудом и показывает скрытую надпись. **Reset** возвращает все три элемента в исходное состояние. При закрытии меню состояния элементов очищаются.

Для проверки доступа открой меню игроком без OP и без `uicore.demo.vip`. **VIP access** должен выглядеть недоступным; обе кнопки доступа должны отклонять клик. Выдай `uicore.demo.vip` через плагин прав и снова открой меню, чтобы показать разрешённый стиль и действия.

Эти примеры не используют перетаскивание или автоматическое вращение предметов. Перед записью проверь внешний вид, совпадение курсора и хитбоксов, а также клики в Minecraft: сборка исходников не проверяет картинку в клиенте.
