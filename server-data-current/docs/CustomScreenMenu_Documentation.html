English Documentation

Authoring, operation, configuration, and troubleshooting

What the plugin does

CustomScreenMenu creates fixed-camera, world-space menus in Minecraft. A player is moved into a controlled camera session, menu entries are rendered as TextDisplay entities, and an item cursor is moved by player rotation packets. Hover and click detection is performed against display hitboxes.

Main features

  • Fixed camera menu sessions with /cursormenu run <menu> or /cmenu run <menu>.
  • Text button layouts with world-space x, y, z coordinates.
  • Hover enlarge, hover sound, hover commands, leave commands, hover tooltip, hover cursor, and text style states.
  • Left-click command execution, menu switching, stop-menu behavior, and optional teleport on exit.
  • Auth/login/register/password flow with local database and IP-binding controls.
  • Item display previews, temporary text displays, WASD navigation, and optional NPC mirror.
  • PlaceholderAPI variables and built-in placeholders such as %player% and %player_world%.
  • MiniMessage support in patched [message], [actionbar], and [link] display text.

Dependencies

  • Required: Paper-compatible server, PlaceholderAPI, PacketEvents.
  • Bundled/runtime library: SQLite JDBC is declared in plugin.yml.
  • Optional: FancyNpcs and SkinsRestorer for NPC mirror features.
  • Optional: CraftEngine for image/text tag compatibility when available.

Quick Start

  1. Place the plugin jar in the server plugins folder.
  2. Install required dependency plugins: PlaceholderAPI and PacketEvents.
  3. Start the server once so the plugin creates its data folder.
  4. Edit menu files under plugins/CustomScreenMenu/menu/.
  5. Reload the plugin with /cmenu reload.
  6. Open a menu with /cmenu run example or /cmenu run orven_hub.
Current private build note: the current tested build is maintained from a decompiled 1.4.8 jar. The jar uses the same active runtime behavior, with local additions for text styling, hover cursor, hover tooltip, pressed style, permission style, and MiniMessage chat output.

Menu File Format

Menu files live in plugins/CustomScreenMenu/menu/. Each file may define one top-level menu key. The menu key is the name used by /cmenu run <menu>.

orven_hub:
  permission: ""
  wasd-enabled: false
  auto-commands:
    enabled: true
    commands:
      - "[actionbar] <green>Menu opened"
    delays:
      - 5
  camera-position:
    distance: 1.5
    world: world
    x: -187
    y: 100
    z: 347
    yaw: 190
    pitch: 0.0
  layout:
    profile:
      permission: ""
      name: "&aProfile"
      x: -1.45
      y: 0.2
      z: 3.5
      tilt:
        x: 0.0
        y: 0.0
        z: 0.0
      text-size: 1.0
      hover-enlarge:
        enabled: true
        scale: 1.15
      command-delay: 6
      next-menu:
        enabled: true
        menu: orven_profile
      stop-menu:
        enabled: true
        teleport:
          enabled: false
          back-original: false
          world: world
          x: 0.0
          y: 64.0
          z: 0.0

Menu root fields

FieldMeaning
permissionPermission required to open the menu. Empty means public.
wasd-enabledEnables WASD selection integration for this menu, if the WASD module is enabled.
auto-commandsCommands executed after opening the menu. Each command can have a matching delay in ticks.
camera-positionFixed camera world location, yaw, pitch, and distance from the menu plane.
layoutNamed menu elements. Each element becomes a TextDisplay button/hit target.

Coordinate model

The menu uses world-space offsets relative to the camera. For each element, x moves horizontally, y moves vertically, and z moves forward from the camera plane. In the current OrvenCraft test menus, elements use z: 3.5 and camera-position.distance: 1.5.

Text Styles, Hover, Pressed, Permission Style

The private patched build adds visual states for TextDisplay menu elements.

SectionPurpose
styleBase text style.
hover-styleText style while the cursor is inside the element hitbox.
pressed-styleShort text style after click. duration is in ticks.
permission-style.allowedStyle applied when the player can use the element.
permission-style.deniedStyle applied when the player lacks the element permission. This has the highest priority.
permission-deniedBehavior when a player without permission clicks the element: message, actionbar, sound, commands, and deny/ignore mode.
hover-tooltipActionbar or chat tooltip when hovering.
hover-cursorTemporarily changes the cursor item material/custom-model-data/scale while hovering.

Style priority is: style -> permission-style.allowed -> hover-style -> pressed-style -> permission-style.denied. Denied style wins so locked buttons stay visibly locked.

vip_button:
  permission: orven.demo.vip
  name: "VIP Button"
  x: 0.0
  y: 0.25
  z: 3.5
  text-size: 0.82
  style:
    color: "#ffd866"
  permission-style:
    allowed:
      color: "#ffd866"
      bold: true
    denied:
      color: "#777777"
      strikethrough: true
  hover-style:
    color: "#ffffff"
    underlined: true
    transition:
      type: smooth
      duration: 5
  pressed-style:
    color: "#ffaa00"
    bold: true
    duration: 3
  hover-tooltip:
    type: actionbar
    text: "<gray>Permission: <yellow>orven.demo.vip</yellow>"
  hover-cursor:
    material: GOLD_INGOT
    custom-model-data: 0
    scale: 1.12
  permission-denied:
    message: "<red>You cannot use this button"
    actionbar: "<gray>Requires <yellow>orven.demo.vip</yellow>"
    sound: minecraft:entity.villager.no
    volume: 0.8
    pitch: 1.0
    click-behavior: deny
    commands:
      - "[message] <gray>Denied command example"
  command:
    - "[message] <gold>VIP button clicked"

Supported style fields: text, color, bold, italic, underlined/underline, strikethrough/strike, obfuscated/magic. Smooth transitions currently interpolate color only; formatting and text changes switch immediately.

Permission denied click behavior

If a player does not pass the element permission check and clicks the button, normal command, random-commands, link, next-menu, and stop-menu actions do not run. Instead, the optional permission-denied block is used. If the block is missing, the plugin falls back to the global permission.no_permission_button message.

FieldMeaning
messageMiniMessage/legacy chat message sent on denied click.
actionbarMiniMessage/legacy actionbar text sent on denied click.
soundSound key played to the player, for example minecraft:entity.villager.no.
volume, pitchDenied sound volume and pitch.
click-behaviordeny runs denied feedback. ignore silently ignores the click.
commandsCommands executed only on denied click. They use the same prefixes as normal click commands.

Security: Menu files are executable configuration. Restrict who can edit them. Be especially careful with [op], [console], and untrusted placeholders inside commands.

Auth, Login, Register, and IP Binding

The current plugin includes an auth surface. It should be treated as an active supported module in this private build, not removed.

  • User data is stored through the plugin database manager and SQLite library.
  • Password fields are managed through menu input commands and local player input state.
  • Password length is currently validated as 6-12 characters, with weak-password checks.
  • Admins can reset passwords and delete user records through commands.
  • config.yml contains IP binding, whitelist, blacklist, lockout, and admin IP whitelist controls.
  • button-access-control can require login or block duplicate registration based on menu/button name tags and key tags.
button-access-control:
  login-required:
    name-tags:
      - "[需要登录]"
    key-tags:
      - "login_required"
  no-duplicate-registration:
    name-tags:
      - "[NO_DUPLICATE_REG]"
    key-tags:
      - "no_duplicate_reg"

ip-binding:
  enabled: true
  strict: false
  allow-same-ip-login: true
  lockout-duration: 5
  max-login-attempts: 5

Item Displays, Text Displays, WASD, NPC Mirror

Item display previews

Configure item previews in items.yml, then show them with /cmenu items <id>. Items can use material, custom model data, scale, offsets, glow, rotation, and rotation speed.

Text display overlays

Configure temporary text displays in text.yml. They can be associated with menus, have single-line or multiline content, scale, position, tilt, animation, duration, and alignment.

WASD navigation

wasd_config.yml controls whether WASD navigation is globally enabled, which menus are included, cooldowns, sound feedback, and disabled players. WASD input is read through PacketEvents player input packets.

NPC mirror

npc_config.yml controls optional NPC mirror behavior. It depends on optional NPC/skin plugins and can sync equipment and skin, use offsets, auto-rotate, and show a formatted name.

Troubleshooting

  • If clicks do not work, check that PacketEvents is installed and loaded before this plugin.
  • If a menu opens and immediately closes, inspect stop-menu, next-menu, permissions, and console errors.
  • If a menu transition closes instead of switching, make sure the old button config does not stop the menu without a valid next-menu.
  • If the denied permission style does not appear, remember that OP players are treated as allowed by current runtime logic.
  • If the cursor cannot reach buttons, tune cursor-item.max-x, max-y, sensitivity, and menu element positions.
  • If commands are blocked while in camera mode, add safe commands to commands.yml.
  • If MiniMessage output appears literally, verify that the patched jar is loaded and not the original jar.

菜单制作、运行、配置与排错

插件功能概览

CustomScreenMenu 用于在 Minecraft 中创建固定相机的世界空间菜单。玩家进入受控相机会话后，菜单元素会以 TextDisplay 实体显示，物品光标会根据玩家视角数据移动，悬停与点击通过显示实体的命中区域判断。

主要功能

  • 使用 /cursormenu run <menu> 或 /cmenu run <menu> 打开固定相机菜单。
  • 使用世界空间 x、y、z 坐标摆放文字按钮。
  • 支持悬停放大、悬停音效、悬停命令、离开命令、悬停提示、悬停光标和文字状态样式。
  • 支持点击执行命令、跳转菜单、关闭菜单和退出传送。
  • 保留登录、注册、密码和 IP 绑定功能。
  • 支持物品展示、临时文字展示、WASD 导航和可选 NPC 镜像。
  • 支持 PlaceholderAPI 和内置变量，例如 %player%、%player_world%。
  • 当前私有补丁版支持在 [message]、[actionbar] 和 [link] 显示文本中使用 MiniMessage。

依赖

  • 必需：Paper 兼容服务端、PlaceholderAPI、PacketEvents。
  • 运行库：plugin.yml 中声明了 SQLite JDBC。
  • 可选：FancyNpcs 与 SkinsRestorer，用于 NPC 镜像功能。
  • 可选：CraftEngine，可用于兼容图片或文本标签。

快速开始

  1. 将插件 jar 放入服务器 plugins 文件夹。
  2. 安装必需依赖插件：PlaceholderAPI 和 PacketEvents。
  3. 启动一次服务器，让插件生成数据文件夹。
  4. 编辑 plugins/CustomScreenMenu/menu/ 下的菜单文件。
  5. 使用 /cmenu reload 重载插件。
  6. 使用 /cmenu run example 或 /cmenu run orven_hub 打开菜单。
当前私有构建说明：当前测试版本基于反编译的 1.4.8 jar 维护。运行逻辑保持原插件方式，并添加了文字样式、悬停光标、悬停提示、按下样式、权限样式和 MiniMessage 聊天输出。

无权限点击行为

如果玩家没有通过元素权限检查并点击按钮，普通的 command、random-commands、link、next-menu 和 stop-menu 不会执行。插件会改用可选的 permission-denied 配置段。如果没有配置该段，则回退到全局 permission.no_permission_button 消息。

字段含义
message无权限点击时发送的聊天消息，支持 MiniMessage 和传统颜色。
actionbar无权限点击时发送的 ActionBar，支持 MiniMessage 和传统颜色。
sound播放给玩家的音效 key，例如 minecraft:entity.villager.no。
volume, pitch无权限音效的音量和音调。
click-behaviordeny 执行无权限反馈；ignore 静默忽略点击。
commands只在无权限点击时执行的命令，使用与普通点击命令相同的前缀。

命令前缀与消息格式

前缀行为
[console]以控制台身份执行命令。
[op]临时给予玩家 OP 后执行命令。权限很高，有风险，只应在可信配置中使用。
[player]以玩家身份执行命令。
[server]通过插件消息将玩家发送到另一个 BungeeCord 服务器。
[message]发送聊天消息。当前私有补丁版支持 MiniMessage 点击、悬停和颜色格式。
[actionbar]发送 ActionBar 消息。当前私有补丁版支持 MiniMessage 颜色和格式。
[link]用于 link 字段，发送可点击打开 URL 的聊天文本。
 
command:
  - "[message] <green>Hello <click:open_url:'https://modrinth.com/plugin/customscreenmenu'><underlined>open page</underlined></click>"
  - "[actionbar] <aqua>Actionbar message"
  - "[player] spawn"
  - "[console] say %player% clicked a menu button"
安全提醒：菜单文件属于可执行配置。请限制可编辑菜单的人。尤其要谨慎使用 [op]、[console] 和命令中的不可信占位符。

登录、注册、密码与 IP 绑定

当前插件包含认证功能。在此私有构建中它是保留并支持的模块，不应删除。

  • 用户数据通过插件数据库管理器和 SQLite 库保存。
  • 密码字段通过菜单输入命令和玩家本地输入状态管理。
  • 当前密码长度验证为 6 到 12 位，并包含弱密码检查。
  • 管理员可以通过命令重置密码或删除用户记录。
  • config.yml 包含 IP 绑定、白名单、黑名单、锁定时间和管理员 IP 白名单。
  • button-access-control 可以根据按钮名称标记或按钮 key 标记要求登录或阻止重复注册。
button-access-control:
  login-required:
    name-tags:
      - "[需要登录]"
    key-tags:
      - "login_required"
  no-duplicate-registration:
    name-tags:
      - "[NO_DUPLICATE_REG]"
    key-tags:
      - "no_duplicate_reg"

ip-binding:
  enabled: true
  strict: false
  allow-same-ip-login: true
  lockout-duration: 5
  max-login-attempts: 5

物品展示、文字展示、WASD、NPC 镜像

物品展示

在 items.yml 中配置物品展示，然后使用 /cmenu items <id> 显示。物品可配置材质、custom model data、缩放、偏移、发光、旋转和旋转速度。

文字展示

在 text.yml 中配置临时文字展示。可绑定菜单，支持单行或多行内容、缩放、位置、倾斜、动画、持续时间和对齐方式。

WASD 导航

wasd_config.yml 控制 WASD 导航是否全局启用、哪些菜单启用、冷却时间、音效反馈和禁用玩家。WASD 输入通过 PacketEvents 玩家输入包读取。

NPC 镜像

npc_config.yml 控制可选 NPC 镜像功能。它依赖可选 NPC/皮肤插件，可同步装备和皮肤，支持偏移、自动旋转和格式化名称显示。

排错

  • 如果点击无效，请检查 PacketEvents 是否安装并且早于本插件加载。
  • 如果菜单打开后立刻关闭，请检查 stop-menu、next-menu、权限和控制台错误。
  • 如果菜单跳转变成关闭，请确认旧按钮配置没有在缺少有效 next-menu 的情况下停止菜单。
  • 如果看不到无权限样式，请注意当前运行逻辑会把 OP 玩家视为有权限。
  • 如果光标无法移动到按钮位置，请调整 cursor-item.max-x、max-y、sensitivity 和菜单元素坐标。
  • 如果固定相机模式下命令被阻止，请将安全命令加入 commands.yml。
  • 如果 MiniMessage 原样显示，请确认服务器加载的是补丁 jar，而不是原始 jar。
