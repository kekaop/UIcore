# План полного аудита UIcore

> **Язык:** [English](BUG_AUDIT_PLAN.md) | Русский

Этот документ фиксирует порядок проверки перед следующим стабильным релизом. Он не добавляет тестовые меню и не копируется в JAR.

## Проверить жизненный цикл

- [ ] Включение и выключение на Paper 1.20.1 и Paper 26.1.2.
- [ ] Включение и выключение на Folia 1.20.1 и 26.2.
- [ ] `/uicore reload` при открытом меню.
- [ ] Быстрое переключение `next-menu` и закрытие сразу после клика.
- [ ] Выход игрока, кик, смерть, смена мира и телепорт во время активной сессии.
- [ ] Два игрока в одном меню и два игрока в разных меню.

## Проверить ввод и hitbox

- [ ] Наведение по верхней и нижней границе текста.
- [ ] Элементы на разной глубине относительно камеры.
- [ ] ЛКМ, ПКМ, удержание, отмена клика и повторный клик после перехода.
- [ ] Ввод через чат, командами и через Java API.
- [ ] Состояние курсора после смены меню и после закрытия.
- Перетаскивание группы и интерактивное вращение удалены из 1.0.0.

## Проверить рендеринг

- [ ] Текст, предметы, hitbox, hover-style, pressed-style и tooltip.
- [ ] Состояния `initial-state`, `set-state` и `set-states`.
- [ ] Слоты, шаблоны и переходы предметов.
- [ ] Схемы Sponge v2/v3, восстановление блоков и смена меню.
- [ ] Масштаб интерфейса, FOV, смена разрешения и перезапуск клиента.

## Проверить интеграции

- [ ] Запуск без Vault и LuckPerms.
- [ ] Запуск с Vault без economy provider.
- [ ] Баланс, форматированный баланс и `vault:has-balance`.
- [ ] LuckPerms primary group, prefix, suffix, наследуемая группа и метаданные.
- [ ] PlaceholderAPI, FancyNpcs, SkinsRestorer и CraftEngine по заявленным версиям.

## Проверить безопасность и отказоустойчивость

- [ ] Команды игрока, консоли и `[op]` с allowlist.
- [ ] Неверные YAML-типы, неизвестные extension IDs и отсутствующие меню.
- [ ] Долгий или ошибочный внешний extension callback.
- [ ] Невалидные координаты, размеры hitbox, scale, duration и numeric expressions.
- [ ] Логи без паролей, токенов и значений секретных input-полей.

## Автоматическая проверка

Запустить:

```text
mvn -q clean package
```

После сборки проверить, что `UIcore-1.0.0.jar` не содержит showcase-файлов, `docs/` или HTML-документации. Игровые пункты нужно отмечать только после проверки обычным клиентом.
