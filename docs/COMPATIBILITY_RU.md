# Совместимость UIcore

Один JAR собирается с `--release 17` против Paper API 1.20.1. В `plugin.yml` указан `api-version: '1.20'` и `folia-supported: true`. Это позволяет загружать его на Paper, Folia, Purpur и Leaf в пределах Minecraft 1.20.1–26.2, если у самого серверного проекта есть сборка для нужной версии. PacketEvents 2.14.0 обязателен.

Матрица выше получена на одной сборке UIcore 1.0.0 с PacketEvents 2.14.0. Сборка дополнительно проверена с подключённым тестовым игроком на Paper и Folia 1.20.1: `/uicore run demo_main` и `/uicore stop` прошли после перевода примера на позицию игрока. На Folia 26.2 сборка прошла запуск и остановку. Остальные строки не повторялись именно для финального JAR. В ранее проверенных сочетаниях `/uicore reload` выполнилась, сервер завершился с кодом 0; ошибок UIcore, `NoSuchMethodError` и `NoClassDefFoundError` в журналах нет. Визуальный вид, все виды взаимодействия и дополнительные интеграции остаются задачами [игровой проверки](SMOKE_CHECKLIST.md). У Leaf сейчас нет опубликованной версии 1.20.1 в [официальном API](https://api.leafmc.one/v2/projects/leaf).

Java 17 — нижний уровень bytecode плагина, а не универсальная Java для сервера: запускайте каждую версию Minecraft на Java, которую требует соответствующая сборка сервера. Поддержка Folia ограничивает расположение элементов пределами региона камеры; подробности — в [статусе переноса](PORT_26_2_RU.md).
