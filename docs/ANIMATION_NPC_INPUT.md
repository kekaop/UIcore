# Animation, NPC, Input, And Cursor Notes

The complete English and Russian authoring reference is maintained in
`docs/UIcore_GitBook.html`. Documentation is distributed with the source
repository and is not copied into the plugin JAR.

The guide covers:

- staged entrance animation and easing, including `ease-out-back`;
- continuous display animation and dynamic coordinate expressions;
- fixed and player-relative camera positioning;
- projected cursor hit-testing across different element depths;
- generic input fields and command placeholders;
- per-menu NPC mirror configuration;
- slots, templates, and animated item transitions.
