# UIcore на Paper и Folia 26.2

Сборка использует bytecode Java 17 и API Paper 1.20.1, чтобы один JAR загружался на версиях Minecraft 1.20.1–26.2. Сервер 26.2 запускается на Java 25. В `plugin.yml` включён `folia-supported: true`; экспериментальная Folia 26.2 beta build 7 загрузила плагин с PacketEvents 2.14.0. Результаты по другим серверам — в [матрице совместимости](COMPATIBILITY_RU.md).

## Что перенесено

- Ввод, состояние меню, команды для игрока и API-операции выполняются в scheduler игрока. Консольные команды уходят в global scheduler.
- Анимации текста, курсора, предметов, typewriter и NPC используют scheduler соответствующих сущностей. Задачи сохраняют отменяемые дескрипторы.
- Тикеты чанков и поиск оставшихся сущностей меню выполняются в scheduler региона чанка. Тикет сохраняется, пока он нужен хотя бы одному игроку.
- Переход к камере и возврат к исходной позиции используют `teleportAsync`. Сцена создаётся только после завершения перехода; после сбоя журнал восстановления остаётся на диске.
- Меню проверяет владение регионом перед созданием элементов. Если камера, курсор или элемент лежат в другом Folia-регионе, открытие прерывается с сообщением в журнале сервера. Динамическое движение не переносит элементы через границу региона.
- Перемещение сущностей меню на Folia выполняется через `teleportAsync`: Folia 1.20.1 запрещает обычный `Entity.teleport()` даже для движения курсора в своём регионе.

## Что проверено

- `mvn -B -ntp -pl uicore-plugin -am clean verify` на JDK 25 с `release 17`: 76 тестов без ошибок.
- Локальные запуски Folia `26.2-7` и Paper `26.2-129` с PacketEvents `2.14.0`: UIcore загрузился, команда `/uicore reload` выполнилась, оба сервера остановились без ошибки плагина.

Игровой сеанс с подключённым клиентом пока не проверен. Перед установкой на рабочий сервер проверьте открытие и закрытие меню, наведение и клик, ввод текста, переключение меню, смерть и переподключение игрока. Отдельно проверьте двух игроков в разных регионах. Интеграции FancyNpcs, SkinsRestorer и CraftEngine также требуют проверки на установленной вами версии этих плагинов.

Для меню, элементы которого должны пересекать границы Folia-регионов, нужна отдельная асинхронная отрисовка каждого элемента. Сейчас такое меню прерывает открытие, сохраняя состояние игрока, вместо обращения к чужому региону.

Основа правил потоков: [Paper: Supporting Paper and Folia](https://docs.papermc.io/paper/dev/folia-support/) и [Folia: Region overview](https://docs.papermc.io/folia/reference/overview/).
