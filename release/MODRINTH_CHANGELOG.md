## UIcore 1.1.0

- **Camera cutscenes** with configurable routes, pauses, and branching choices.
- **Drag and drop** with parent groups, sliders, drop targets, YAML `on-drop` actions, and Java `MenuDropEvent`.
- **Mouse-wheel zoom** for menus or individual groups. Visuals and hitboxes scale together.
- **New demos** to try each feature: `demo_cutscene`, `demo_drag`, and `demo_zoom`.
- **Fixes** for hit testing, action context, configuration reload, and player state recovery.

Requires [PacketEvents 2.14.0 Spigot](https://modrinth.com/plugin/packetevents/version/m78nFxYg) on the server. Hold-to-drag is experimental. Zoom works with two-click drag.

## Что нового в 1.1.0

- **Катсцены** с маршрутами камеры, паузами и ветками выбора.
- **Перетаскивание** с родительскими группами, ползунками, зонами сброса, YAML-действиями `on-drop` и Java-событием `MenuDropEvent`.
- **Зум колёсиком** для меню и отдельных групп. Хитбоксы масштабируются вместе с элементами.
- **Новые демо**: `demo_cutscene`, `demo_drag` и `demo_zoom`.
- **Исправления** расчёта хитбоксов, контекста действий, перезагрузки конфигурации и восстановления состояния игрока.

На сервере нужен [PacketEvents 2.14.0 Spigot](https://modrinth.com/plugin/packetevents/version/m78nFxYg). Удержание ЛКМ экспериментальное. Зум работает с перетаскиванием в два клика.
