# Проверки релиза UIcore 1.1.0

> **Язык:** [English](VALIDATION.md) | Русский

Проверка прошла 22 ноября 2026 года. Релизный JAR собран в Windows на JDK 25 командой `mvn -B -ntp clean verify`.

| Проверка | Результат |
| --- | --- |
| Тесты Maven | Прошли все 205 |
| Paper 26.1.2 build 72 и Folia 26.1.2 build 8 | По девять сценариев взаимодействия на каждом ядре с PacketEvents 2.14.0 |
| Протокольная проверка катсцен | В успешном прогоне по 40 кликов на каждом ядре. Проверены наведение, кадры, камера и восстановление режима игры |
| Проверка JAR | Версия 1.1.0 в описании плагина и конфиге, bytecode Java 17, шесть демоменю, катсцена и обязательная зависимость PacketEvents |

В первом прогоне катсцен на Folia прошло 9 из 10 кликов в начальной серии. Повторный прогон принял все 40. При остановке первого прогона с открытым меню Folia записала предупреждения об очистке. В успешных прогонах меню закрывались до остановки. Протокольные тесты отправляют пакеты напрямую. Перетаскивание реальной мышью и плавность катсцен на подключённом клиенте для этого JAR требуют игровой проверки.
