# UIcore — UI that lives in your Minecraft world

Build interactive menus around the player's camera with text, items, avatars, and animated elements. Configure scenes in YAML or extend them through the Java API. Players use a visual cursor to explore controls, switch menus, and enter text through chat.

## Features

- Hover effects, cursor styles, click animations, and tooltips.
- Input fields, toggles, element states, permissions, and cooldowns.
- Item displays, player avatars, reusable templates, and slots.
- Personal Sponge `.schem` v2/v3 previews without changing world blocks.
- Menu privacy, player visibility controls, and optional protection from player damage.
- Built-in integrations for Vault and LuckPerms; optional support for PlaceholderAPI, FancyNpcs, SkinsRestorer, and CraftEngine.
- A Java API for actions, data providers, conditions, and components.
- Three bundled demo menus that work without a resource pack.

**Requirements:** Minecraft 1.21.1+, Paper or a compatible server, and PacketEvents 2.14.0. Folia scenes must stay within one region. Use the Java runtime required by your server.

[Videos, documentation, and source code](https://github.com/kekaop/UIcore). See the documentation for tested server builds and client compatibility notes.
