# UIcore 1.1.0

> **Язык:** [English](RELEASE_NOTES.md) | Русский

В UIcore 1.1.0 можно делать интерактивные туры, перетаскиваемые панели и меню с масштабированием вокруг камеры игрока. Для этого достаточно ванильного клиента Minecraft.

## Катсцены

- Настраивайте маршруты, повороты, паузы и ветки выбора в YAML. Скорость движения и вращения задаётся отдельно, а камера и прогресс хранятся для каждого игрока.
- Привязывайте катсцену к меню, запускайте её действием или через Java API и сохраняйте точки камеры прямо в игре.
- Попробуйте `/uicore run demo_cutscene`. [Руководство по катсценам](https://github.com/kekaop/UIcore/wiki/Cutscenes-RU)

## Перетаскивание, группы и ползунки

- Используйте `parent`, чтобы дочерние элементы перемещались вместе с группой. Настраивайте ручки захвата, границы перемещения и допустимые точки сброса.
- После успешного сброса можно запустить YAML-действия через `on-drop` или обработать Java-событие `MenuDropEvent`. Ползунки записывают значения с заданным шагом в состояние меню.
- По умолчанию перетаскивание работает в два клика. В `demo_drag` доступно экспериментальное удержание ЛКМ для неподвижных меню. В этом режиме Minecraft может показывать прицел. [Руководство по взаимодействиям](https://github.com/kekaop/UIcore/wiki/Interactions-RU)

## Зум колёсиком

- Масштабируйте меню целиком или отдельную группу. Настраиваются диапазон, точка масштабирования и плавность. Хитбоксы элементов и зон сброса масштабируются вместе с ними.
- Попробуйте `/uicore run demo_zoom`. Зум работает с перетаскиванием в два клика. [Настройка зума](https://github.com/kekaop/UIcore/wiki/Interactions-RU#зум-колёсиком)

## Исправления и обновление

- Исправили расчёт хитбоксов трансформированных элементов и привели отрисовку и ввод к одному кадру меню.
- Исправили контекст обычных и отложенных действий. Ошибка при перезагрузке оставляет действующие настройки активными.
- Улучшили восстановление исходного состояния игрока при неожиданном завершении сеанса меню.
- Установите `UIcore-1.1.0.jar` и [PacketEvents 2.14.0 Spigot](https://modrinth.com/plugin/packetevents/version/m78nFxYg) в `plugins/` и перезапустите сервер.
