# UIcore 1.0.0

> **Язык:** [English](RELEASE_NOTES.md) | Русский

Первый релиз UIcore на основе CustomScreenMenu 1.4.8. Плагин рассчитан на Minecraft 1.21.1 и новее. Для доступных сборок Paper, Folia, Purpur и Leaf проверялись запуск, перезагрузка и выключение; подробности приведены в [матрице совместимости](../docs/COMPATIBILITY_RU.md).

В этом выпуске добавлены состояния отдельных элементов (`initial-state`, `states`, `set-state`, `set-states`) и персональные превью схем Sponge `.schem` v2/v3. Сохранены permission conditions. Переработаны восстановление игрока после закрытия меню, жизненный цикл сущностей и задач, проверки конфигурации и обработка клика/ввода. Реализована работа с планировщиками Folia; JAR собирается против Paper API 1.21.1 с Java 17 bytecode.

Известные ограничения: схемы показывают состояния блоков без данных block entities, сущностей и биомов; отдельные интеграции с дополнительными плагинами требуют проверки на конкретной серверной сборке. Экспериментальное перетаскивание меню в релиз не включено.

## Включённые исправления

- Восстановление старого blockcache выполняет операции с каждым блоком в его регионе Folia, затем сохраняет журнал после получения всех результатов. Ошибочные и конфликтующие записи остаются для повторной попытки.
- Глобальные изменения элементов через API выполняются последовательно в пределах меню; рендер читает неизменяемые снимки определений.
- Теги изображений и смещений CraftEngine добавляются через builder резолверов Adventure вместе со стандартными тегами.
- Тест с отдельным процессом выбирает `java` в Linux и `java.exe` в Windows.
- Для каждого меню доступны независимые настройки видимости сущностей, видимости игроков в обе стороны и входящего урона от игроков. См. [настройки видимости и урона](../docs/MENU_AUTHORING_GUIDE_RU.md#настройте-видимость-меню-и-урон-игроку).

- Удалены остатки экспериментального захвата ЛКМ, перемещения групп и интерактивного вращения, а также устаревшие примеры конфигурации.
- Маркер внутреннего телепорта сверяет назначение; завершение старого запроса не сбрасывает новый маркер.
- Команды после перехода между entity/global scheduler проверяют актуальность исходного сеанса меню.
- Конфигурация отклоняет permission не строкового типа и click-requirements не в виде секции.
- Пустые результаты и ошибки источника данных расширения кэшируются на заданный интервал обновления.
- Для сборки указан JDK 21 или новее; результаты сборки примера расширения исключены из репозитория.

Эти пути покрыты автоматическими тестами. Отображение для нескольких игроков и дополнительные интеграции ещё требуют игровых проверок на целевом сервере. Тест с отдельным процессом выполнялся в Windows; запуск в Linux остаётся непроверенным.
