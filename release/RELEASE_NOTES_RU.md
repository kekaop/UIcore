# UIcore 1.0.0

Первый публичный релиз UIcore на основе CustomScreenMenu 1.4.8. Сборка рассчитана на Minecraft 1.20.1–26.2 и проверялась на доступных сборках Paper, Folia, Purpur и Leaf. Полная матрица и границы проверки приведены в [документе совместимости](../docs/COMPATIBILITY_RU.md).

В этом выпуске добавлены состояния отдельных элементов (`initial-state`, `states`, `set-state`, `set-states`) и персональные превью схем Sponge `.schem` v2/v3. Сохранены permission conditions. Переработаны восстановление игрока после закрытия меню, жизненный цикл сущностей и задач, проверки конфигурации и обработка клика/ввода. Реализована работа с планировщиками Folia; JAR собирается против Paper API 1.20.1 с Java 17 bytecode.

Известные ограничения: схемы показывают состояния блоков без данных block entities, сущностей и биомов; отдельные интеграции с дополнительными плагинами требуют проверки на конкретной серверной сборке. Экспериментальное перетаскивание меню в релиз не включено.
