# UIcore — проект карточки товара

**Черновик для Millida Market и Black-Minecraft.com. Не публиковать до закрытия [проверок перед продажей](SALE_READINESS_RU.md).**

UIcore — плагин для интерактивных меню, размещённых прямо в игровом мире Minecraft. Текст, предметы и кнопки описываются в YAML. Для элемента можно задать состояния и менять их по нажатию, а также показывать игроку превью схем `.schem` без изменения блоков мира.

**Возможности:** меню из текста и предметов; действия по клику; состояния отдельных элементов (`initial-state`, `states`, `set-state`, `set-states`); conditions, включая проверки прав; персональные превью схем Sponge v2/v3; API для других плагинов; настройка из YAML и команда `/uicore reload`.

**Требования:** сервер Paper, Folia, Purpur или Leaf на Minecraft 1.21.1 и новее; установленный PacketEvents 2.14.0; Java, подходящая для выбранной версии сервера. Подробная [матрица проверенных сборок](../docs/COMPATIBILITY_RU.md) входит в архив. PlaceholderAPI, FancyNpcs, SkinsRestorer и CraftEngine — дополнительные интеграции; их работу нужно проверять на конкретных версиях.

**Комплект:** бинарный `UIcore.jar`, инструкция, справочник YAML, матрица совместимости, уведомления о сторонних компонентах и исходники включённой библиотеки MorePaperLib с инструкцией по её пересборке. Исходники UIcore в комплект не входят. UIcore основан на [CustomScreenMenu](https://github.com/JSGDJD/CustomScreenMenu) и распространяется как отдельная доработанная сборка с разрешения автора. Права на MorePaperLib регулируются LGPLv3+.

**Ограничения:** перетаскивание всего меню с зажатой ЛКМ в этот выпуск не входит. На Folia элементы сцены следует размещать в регионе камеры. Превью схем не показывает данные контейнеров и других block entities, сущности и биомы. На 26.2 подтверждён запуск серверов, но полный сценарий игры обычным клиентом пока не завершён.
