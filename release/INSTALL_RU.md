# Установка UIcore 1.0.0

UIcore создаёт меню из элементов в игровом мире: текст, предметы, кнопки, состояния элементов и индивидуальные для игрока превью схем. Меню управляется через YAML и команды плагина.

## Установите плагин

1. Остановите сервер и сохраните резервную копию мира и папки `plugins/UIcore/`, если обновляете действующую установку.
2. Поместите `UIcore.jar` из архива и PacketEvents **2.14.0** в папку `plugins/`.
3. Запустите сервер. UIcore создаст конфигурацию и примеры меню в `plugins/UIcore/menu/`.
4. Встаньте в свободном месте и выполните `/uicore run demo_main`. Закройте меню командой `/uicore stop`.

UIcore поддерживает Minecraft 1.21.1 и новее. Он собирается с Java 17 bytecode; запускайте сервер на версии Java, которую требует выбранная сборка. Проверенные серверы и глубина проверки указаны в [матрице совместимости](../docs/COMPATIBILITY_RU.md). PacketEvents обязателен; PlaceholderAPI, FancyNpcs, SkinsRestorer, CraftEngine, Vault и LuckPerms — дополнительные интеграции.

## Настройте своё меню

Создайте отдельный `.yml` в `plugins/UIcore/menu/`. Примеры `demo_*` показывают синтаксис; они не меняют ваши существующие файлы. Для первой настройки используйте `camera-position.type: player`, чтобы меню открывалось рядом с игроком. После правки выполните `/uicore reload` и проверьте журнал на ошибки YAML. Полный синтаксис описан в [справочнике](../docs/MENU_AUTHORING_GUIDE_RU.md).

Команды `[console]` в меню по умолчанию отключены. Если они нужны, разрешите только проверенные вами команды через `security.allow-console-commands` и `security.console-command-allowlist` в `config.yml`.

Для превью схем положите Sponge `.schem` v2 или v3 в `plugins/UIcore/schematics/`, укажите файл в секции `schematics:` меню и выполните `/uicore reload`. Превью отправляется только игроку и не меняет блоки мира. Содержимое контейнеров и других block entities, сущности и биомы сейчас не показываются.

На Folia элементы одной сцены должны находиться в регионе камеры. Если большое меню пересекает границу региона, используйте другую точку камеры или уменьшите расстояние до элементов.

## Обновите действующий сервер

Остановите сервер перед заменой JAR. Сохраните свои YAML и схемы, затем замените только файл UIcore в `plugins/`. После запуска проверьте `/uicore run` для основных меню, клики, переключение сцен, `/uicore stop` и отсутствие ошибок в журнале. Не заменяйте свои конфиги файлами из архива: новые примеры появляются только при отсутствии одноимённого файла.

Перетаскивание всего меню удержанием ЛКМ в этот выпуск не входит. Обычный клик ЛКМ и ПКМ по элементам сохранён.
